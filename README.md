# StarReader

Нативная iOS-читалка на **SwiftUI**, которая заменяет прежнее приложение StarReader при установке поверх него.

## Иконка — вариант № 2 (glassmorphism)

По выбору пользователя установлена стеклянная книга со светящейся звездой
на сине-фиолетовом фоне. Исходная иллюстрация в Art/StarReader-Glass-Icon.jpg,
а .ci/generate_icon.swift собирает из неё 1024×1024 AppIcon для iOS.
Версия 0.5.1, Build 52. Сохранён Bundle ID dev.starreader.personalreader;
все функции редактора глав 0.5.1 остались неизменными.
## Принципы

- Нативный интерфейс SwiftUI; без WKWebView, HTML, CSS, JavaScript или Capacitor.
- Локальная библиотека, без обязательной регистрации, облака и подписки.
- Bundle ID: `dev.starreader.personalreader` — совпадает с прежним StarReader, чтобы IPA устанавливался как обновление, а не как отдельное четвёртое приложение.
- Импорт резервной копии StarReader Qt Transfer с проверкой манифеста, SHA-256, допустимых путей и ограничений ZIP.
- Исходный ZIP сохраняется в контейнере приложения как дополнительная резервная копия.
- Сборка unsigned IPA выполняется GitHub Actions на macOS; подпись для личной установки выполняется через Sideloadly.

## Важно перед заменой старого приложения

1. В старом StarReader экспортируй библиотеку в ZIP формата **StarReader Qt Transfer**.
2. Сохрани ZIP в приложении «Файлы» (лучше также сделать вторую копию в другом месте).
3. Не удаляй старый StarReader вручную.
4. Установи новый IPA через Sideloadly с тем же Apple ID / Team, которым подписан старый StarReader. При совпадающих Bundle ID и команде подписи установка должна пройти как обновление.
5. После установки открой StarReader, импортируй ZIP через кнопку импорта и проверь произведения, главы, заметки, закладки и прогресс чтения.
6. Не удаляй внешний ZIP, пока не убедишься, что всё перенеслось и открывается корректно.

Если Sideloadly предлагает удалить старое приложение или показывает конфликт идентификатора/подписи, отмени установку и сначала проверь Bundle ID и Team ID. Не соглашайся на удаление, пока не проверена резервная копия.

## Обновление 0.5.1 — редактор глав

- В режиме страниц выдели фрагмент нативным iOS-выделением и выбери **«Изменить»**. Замени текст или удали его, подтвердив сохранение.
- На верхней панели читалки появилась кнопка карандаша: она открывает полный редактор названия и текста текущей главы, также доступный в режиме прокрутки.
- Абзацы в полном редакторе разделяются пустой строкой. Можно исправлять, удалять и добавлять абзацы. «Отменить правки» возвращает исходный текст, а при закрытии с несохранёнными изменениями появляется предупреждение.
- Каждый коммит главы сохраняет две резервные копии (qt_library.json и preview_state.json) в Application Support/StarReaderNative/Edits/BeforeEdit-UUID. Оригинальные DOCX остаются неизменными.
- ID главы не меняется; рядом с неизменёнными фрагментами заметки, закладки и позиция чтения переносятся по точным Unicode-scalar координатам. Если текст заметки пересекается с исправлением, она не удаляется, а получает статус needs_review, старую цитату и пометку в разделе замечаний.
- Закладки, затронутые правкой, сохраняются с флагом needsReview и предупреждением в списке. Перед сохранением пользователь видит число затронутых записей.
- После сохранения текст немедленно обновляется в режиме чтения, перепагинируется без удаления закладок и попадает в ZIP-экспорт (JSON). Редактирование не обновляет оригинальный DOCX; экспорт самого отредактированного DOCX запланирован отдельно.
- Автотесты проверяют замену выделенного текста, сохранение остальных глав и неизвестных JSON-полей, привязки замечаний, безопасность оригинала, блокировку устаревшего редактора.
## Обновление 0.5.0 — резервное копирование и подсчёт страниц

- Из главного экрана StarReader можно создать ZIP-резервную копию через карточку «Резервная копия библиотеки» или кнопку экспорта в верхней панели.
- Архив включает JSON библиотеки, JSON заметок/закладок/позиций и оригинальные DOCX, которые реально связаны с присутствующими главами. Удалённые главы не возвращаются.
- Формат архива: StarReader Qt Transfer (schema 1) с SHA-256; готовый ZIP проходит повторное чтение текущим `TransferImporter` перед показом системного окна «Поделиться/Сохранить в Файлы». Если отсутствует обязательный оригинальный DOCX или найдена ошибка целостности, экспорт прерывается.
- Локальное состояние не изменяется при экспорте. ZIP создаётся во временной папке, а его сохранение в «Файлы» выбирает пользователь.
- В карточке произведения показывается общее число страниц всех глав, рядом с каждым томом в списке — его количество страниц, внутри тома — общее число страниц и количество страниц отдельных глав.
- Подсчёт выполняется текущим движком TextKit (`NativeTextPagePlan`), а не по символам: размеры, межстрочный и межабзацный интервалы учитываются.
- До первого открытия читалки используется предварительный размер экрана, поэтому число страниц помечается `≈`. Как только известны реальные размеры области чтения, оно пересчитывается и показывается без приближённого знака.
- Счётчики пересчитываются после импорта/удаления глав или изменения шрифта и интервалов. Для больших библиотек подсчёт выполняется по главам с постепенным обновлением интерфейса.
- Устанавливается через Sideloadly поверх версии 0.4.9; перед установкой стоит сохранить старую копию. Подписка и облачные сервисы не требуются.
## Обновление 0.4.9 — импорт отдельных глав из DOCX

- В библиотеке появился значок документа с плюсиком для выбора одного файла Word (.docx) прямо из iOS «Файлы».
- После выбора открывается экран предпросмотра с количеством абзацев, выбором существующего или созданием нового произведения и тома, а также редактированием названия главы.
- Для уже существующего названия в томе требуется отдельное подтверждение «Добавить отдельным вариантом»; без этого дубликаты не импортируются. Существующие главы автоматически не заменяются.
- DOCX разбирается из WordprocessingML: сохраняются текстовые абзацы, порядок текстовых фрагментов, переносы внутри абзацев и базовые заголовки. Изображения, сноски и сложное оформление Word не переносятся.
- Безопасные лимиты: DOCX до 40 МБ, XML до 55 МБ, максимум 35 тысяч абзацев и 8 миллионов символов.
- Библиотека пополняется главой с уникальным ID, существующие тексты, заметки, закладки, прогресс и дополнительные поля JSON не изменяются.
- Оригинальный DOCX сохраняется локально, а перед записью делается резервная копия предыдущего JSON библиотеки и состояния в Imports/BeforeDocx-UUID.
- GitHub Actions тестирует создание библиотеки, создание тома, подтверждение дубликата, сохранение полей и отказ при некорректном JSON.

## Обновление 0.4.7 — удаление глав и томов

- На экране произведения у каждого тома есть кнопка «…» → «Удалить том». На экране тома такая же кнопка → «Удалить главу».
- Перед удалением требуется подтверждение с предупреждением о связанных заметках, закладках и сохранённом прогрессе.
- Удаление происходит по уникальному ID главы, а не её заголовку: если в томе несколько одинаковых «Прологов», остальные сохранятся.
- При удалении тома удаляются все связанные главы, их заметки, закладки и прогресс; само произведение остаётся.
- Перед любой операцией сохраняется отдельная локальная резервная копия файлов qt_library.json и preview_state.json в Application Support/StarReaderNative/Deletes/BeforeDelete-*.
- Исходные DOCX не удаляются, чтобы избежать потери файлов, которые могли использоваться другими главами. Исходные импортированные ZIP также сохраняются.
- Правятся реальные JSON-файлы (а не только видимый список): удалённое не появится снова после перезапуска. Если импортировать старый ZIP, удалённые главы вернутся из него.
- Поддержка глав с одинаковыми названиями, сохранение неизвестных полей JSON и существующих несвязанных заметок проверяются отдельным Swift-тестом в GitHub Actions.

## Исправление 0.4.6 — перенос строк внутри страницы

- Исправлена регрессия 0.4.5: при `UITextView.isScrollEnabled = false` внутренняя ширина текстового контейнера на iPhone не была корректно ограничена, из-за чего строки выходили за экран, а страница выглядела почти пустой.
- Системная компоновка `UITextView` снова работает в режиме `isScrollEnabled = true`, но `panGestureRecognizer` отключён: пользователь перелистывает страницы, а не прокручивает текст внутри одной страницы.
- Геометрия `NSTextContainer` проверяется при каждом изменении реального размера вида; ширина всегда ограничена доступной областью с учётом полей.
- После смены страницы `contentOffset` сбрасывается в ноль: ни одна предыдущая строка не должна появляться сверху.
- На последнюю строку каждой страницы оставлен запас высоты для особенностей текстовой разметки.
- Подсветка и оранжевая полоса для замечаний, системное выделение iOS и формат библиотеки сохранены.
- **Не считать визуально проверенным до теста на iPhone**, даже при успешной компиляции.

## Обновление 0.4.5 — исправление страниц и оформление замечаний

- Каждая страница теперь отображает **собственный непрерывный фрагмент главы** в отдельном не прокручиваемом UITextView. Ранее единая высокая UITextView прокручивалась по Y-offset, из-за чего края страниц обрезались.
- Границы страниц получаются от реальных строк TextKit; источник текста и UTF-16-диапазоны заметок остаются прежними.
- Замечания подсвечиваются полупрозрачным оранжевым фоном и вертикальной оранжевой полосой слева вдоль помеченных строк. Цвет самого текста не меняется.
- Нативные системные маркеры выделения и действие «Замечание» сохранены. Локальные диапазоны выделения переводятся в координаты главы перед сохранением.
- Учитываются постоянные поля текста, 29pt строка прогресса и фиксированное место панели навигации.
- Требуется проверка **на iPhone**: перелистывание вперёд/назад через выделенный многострочный фрагмент, отсутствие пропусков/дубликатов строк, создание замечания в середине абзаца, сохранение прогресса. Нельзя считать тестирование завершённым только по успешной сборке.

## Сборка

GitHub Actions → **Build unsigned iOS IPA**. После успешного запуска скачай артефакт `StarReaderNative-unsigned-ipa`, распакуй ZIP и установи IPA через Sideloadly.

Для локальной генерации проекта на Mac:

```bash
brew install xcodegen
xcodegen generate --spec project.yml
xcodebuild -resolvePackageDependencies -project StarReaderNative.xcodeproj -scheme StarReaderNative
```

## Формат переноса

Ожидается ZIP формата `starreader-qt-library-transfer`, schema 1:
- `starreader-library-manifest.json`;
- `data/qt_library.json` (schema 2);
- `data/preview_state.json` (schema 1);
- `originals/*.docx` (если присутствуют в библиотеке).

Неизвестные поля JSON сохраняются без переписывания при импорте. Перед заменой текущей библиотеки приложение показывает сводку и требует подтверждения.


## Чтение в 0.4.1

- Постраничный режим на **CoreText**: страницы рассчитываются по реальной доступной ширине и высоте экрана с учётом размера шрифта, межстрочного расстояния и отступов между абзацами.
- Касание левого/правого края перелистывает страницу. Касание центра показывает или скрывает верхнее меню.
- Информационная строка внизу видна **всегда** и занимает одну строку: `1/100 стр. • 0,23% • 01:27` (числа — пример, не фиктивные данные).
- Информационная строка размещается вне контейнера с текстом, поэтому не перекрывает строки книги.
- Позиция чтения сохраняется с указанием абзаца и смещения внутри него. При открытии главы выполняется переход к соответствующей странице.
- В меню «Аа» доступны режимы «Страницы» и «Прокрутка», размер шрифта и интервалы.
- В режиме прокрутки номер «виртуальной страницы» приблизительно соответствует разметке CoreText; постраничный режим использует фактические границы страниц.
- Перенесённые замечания остаются в библиотеке, а подсветка их диапазонов отображается и в режиме CoreText.

**Ограничения:** выделение текста и создание новых замечаний непосредственно на странице пока не реализованы; версию нужно проверить на физическом iPhone перед признанием стабильной.


## 0.4.2 — исправлено изменение страниц при скрытии меню

В 0.4.1 верхняя панель действительно скрывалась через `.toolbar(.hidden, for: .navigationBar)`. iOS меняла высоту полезного пространства; CoreText перестраивал границы страниц и сбрасывал текущую страницу/число страниц.

В 0.4.2 навигационная панель **всегда резервирует ту же высоту**, но её заголовок и кнопки плавно становятся невидимыми и перестают принимать нажатия. Физическая область текста, разметка, номер текущей страницы и общее количество страниц **не меняются** от одного нажатия по центру.

Тонкая статусная строка `N/M стр. • 25,86% • 15:15` остаётся видимой постоянно и занимает отдельные 29 pt, не перекрывая книгу. Настоящая переразметка страниц происходит только при изменении размера окна/ориентации, режима чтения или типографики. Такой подход сознательно не добавляет высоту освободившейся панели к области книги: это обеспечивает стабильные границы страниц.

Перед установкой держите резервный ZIP библиотеки вне контейнера приложения. Обновление использует прежний Bundle ID `dev.starreader.personalreader` и предназначено для установки поверх предыдущей версии с той же командой подписи.


## 0.4.3 — текстовые замечания и свайпы

- В постраничном режиме удерживай палец на слове (примерно треть секунды), затем веди его по тексту. Выделение берётся из настоящих CoreText-глифов и привязывается к символам, абзацам и исходному тексту.
- Можно выделять текст внутри нескольких абзацев на странице. Для выделения через границу страницы нажми кнопку продления выделения вправо. Это не меняет сохранённую позицию чтения.
- В контекстной панели нажми «Заметка», выбери Канон / Сюжет / Стиль / Цитата и добавь комментарий (необязательно). Запись сохраняется локально в preview_state.json в том же формате, что импортированные заметки.
- Есть копирование выделенного текста и отмена выделения.
- Свайп влево открывает следующую страницу, вправо — предыдущую; нажатия по краям по-прежнему работают.
- Сохранены стабильная высота области чтения при скрытии верхней панели, реальное количество страниц и **постоянная строка статуса**.
- Новые заметки и старые импортированные записи сохраняются в одном массиве без удаления неизвестных полей.
- В режиме непрерывной прокрутки создание замечаний через выделение пока не поддерживается. Для этой функции переключись на «Страницы».
- Навигационные и анимационные жесты требуют проверки на реальном iPhone. Стабильная версия 0.4.2 остаётся в истории GitHub для восстановления.


## 0.4.4 — системное выделение iOS

После теста 0.4.3 на настоящем iPhone заменён собственный `UILongPressGestureRecognizer` с ручным вычислением символов и рисованием CoreText на настоящий `UITextView` с `isSelectable = true`. Выделение выполняется системным интерфейсом iOS: маркеры, меню копирования, возможности изменения границ. Команда «Замечание» добавлена в стандартное меню редактирования `UITextViewDelegate.textView(_:editMenuForTextIn:suggestedActions:)`.

Вместо отдельного CoreText-рисунка страница размечается через **TextKit NSLayoutManager**; тот же текстовый движок отображает глифы и обрабатывает системные выделения. Это устраняет разницу геометрии между самодельной подсветкой и текстом. Новая постраничная разметка может показывать другое количество страниц при том же размере шрифта — это ожидаемо, так как теперь страницы определяются TextKit.

Сохранены:
- прежний Bundle ID, локальная библиотека и все старые замечания;
- реальный счётчик страниц, процент, часы в постоянно видимой нижней строке;
- высота навигационной области при скрытии кнопок;
- нажатия по краям и горизонтальные свайпы для перелистывания, пока системный текст не выделен;
- редактор замечаний Канон / Сюжет / Стиль / Цитата.

**Проверка на iPhone обязательна**: корректность текста после открытия и после вызова системного меню, перемещение маркеров, выделение нескольких абзацев, возврат из редактора заметки, перелистывание и восстановление прогресса. Не удалять приложение перед обновлением; иметь ZIP резервной копии вне контейнера.
