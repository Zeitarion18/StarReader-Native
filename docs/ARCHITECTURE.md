# Архитектура StarReader Native

## Технологии

- SwiftUI — навигация и интерфейс.
- Foundation — локальные файлы и JSON.
- ZIPFoundation — чтение ZIP без распаковки произвольных путей на диск.
- CryptoKit — SHA-256 для проверки каждого файла из манифеста.
- GitHub Actions + macOS + XcodeGen — воспроизводимая сборка unsigned IPA.

## Границы N0

N0 — рабочий каркас, который проверяет путь миграции и базовое чтение. Он не пытается сразу повторить весь функционал старой читалки.

В N0 уже предусмотрены:
1. отдельный Bundle ID;
2. импорт через системный файловый picker;
3. проверка структуры и целостности ZIP до изменения локальной библиотеки;
4. сохранение исходного ZIP;
5. локальное чтение и сохранение позиции на уровне абзаца.

Пагинация, точный offset внутри абзаца, выделение нескольких абзацев, заметки, закладки, DOCX-импорт и синхронизация будут добавляться отдельными этапами.

## Хранение

В Application Support/StarReaderNative:
- `qt_library.json` — исходный JSON библиотеки;
- `preview_state.json` — исходное состояние чтения и прогресс;
- `originals/` — оригинальные DOCX;
- `Imports/` — неизменённые ZIP-резервные копии.

Импорт не сериализует обратно и не нормализует неизвестные поля JSON. При сохранении позиции обновляется только объект `progress` в состоянии чтения; остальные ключи сохраняются.
