# StarReader Qt Transfer — формат импорта

## Архив

- Максимальный размер ZIP: 350 MiB.
- Максимальное количество записей: 1 600.
- Максимальный размер одного распакованного файла: 120 MiB.
- Максимальный суммарный распакованный размер: 500 MiB.
- Запрещены неизвестные пути, каталоги и ссылки.
- Для файлов из манифеста проверяются размер и SHA-256.

## Манифест

Файл `starreader-library-manifest.json` должен содержать:
- `format = starreader-qt-library-transfer`;
- `schema = 1`;
- массив `files`, каждый элемент которого содержит `path`, `size`, `sha256`.

Разрешённые пути:
- `data/qt_library.json`;
- `data/preview_state.json`;
- `originals/<safe-name>.docx`.

## Данные

`qt_library.json`: schema 2; массивы `works`, `volumes`, `books`, `trash`. Каждая глава должна иметь уникальный строковый `id` и массив `paragraphs`, в котором каждый абзац содержит строковый `text`.

`preview_state.json`: schema 1; объекты `progress` и `settings`, массивы `annotations` и `bookmarks`.

Если в главе указано поле `originalFile`, соответствующий файл должен присутствовать в `originals/`.

## Защита от потери данных

- Содержимое ZIP проверяется до замены текущей библиотеки.
- Пользователь подтверждает замену отдельным действием.
- Исходный ZIP сохраняется в каталоге `Imports/`.
- JSON сохраняется в исходном виде; неизвестные поля не отбрасываются.
